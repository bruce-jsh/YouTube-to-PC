## ใช้ได้อย่างสบายใจ

**ไม่ต้องติดตั้งอะไรเพิ่ม**
ไม่ต้องมี .NET Framework, Visual C++ Redistributable, Python หรืออะไรทำนองนั้น
เป็นโปรแกรม Win32 ที่ใช้เฉพาะสิ่งที่ Windows มีอยู่แล้ว ดาวน์โหลดแล้วเปิดใช้ได้เลย

**ไม่มีโฆษณาเลยแม้แต่ชิ้นเดียว**
ไม่มีแบนเนอร์ ไม่มีหน้าต่างเด้ง ไม่มีข้อความชวนให้ "อัปเกรดเดี๋ยวนี้"
และไม่มีรุ่นเสียเงินด้วย

**ไม่เก็บข้อมูลส่วนตัว**
ไม่ต้องสมัครสมาชิก ไม่ต้องลงชื่อเข้าใช้ ไม่มีการส่งข้อมูลการใช้งานไปที่ใดทั้งสิ้น
การตั้งค่าและรายการดาวน์โหลดอยู่ในเครื่องของคุณเท่านั้น

**ไม่มีโปรแกรมแถมพ่วง**
ตอนติดตั้งจะไม่แอบใส่โปรแกรมอื่น และไม่ไปยุ่งกับการตั้งค่าเบราว์เซอร์

## ความสามารถ

- กด **วางลิงก์** แล้วเริ่มดาวน์โหลดทันที (ใช้ `Ctrl+V` ก็ได้)
- เลือก **วิดีโอ** (MP4, MKV) หรือ **เพลง** (MP3, M4A)
- คุณภาพตั้งแต่ **สูงสุดเท่าที่มี** จนถึง 144p และเสียงตั้งแต่ดีที่สุดจนถึง 128 kbps
- ดาวน์โหลด **ทั้งเพลย์ลิสต์หรือทั้งช่อง** หรือเลือกเฉพาะวิดีโอที่ต้องการ
- เลือก **คำบรรยายและแทร็กเสียง** ราว 85 ภาษา แสดงด้วยตัวอักษรของภาษานั้น ๆ
- ดาวน์โหลดพร้อมกันได้ 1 ถึง 8 รายการ
- **ธีมสว่างและมืด** หรือตามการตั้งค่าของ Windows
- รองรับ **15 ภาษา**
- แสดงภาพย่อ ความคืบหน้า และเวลาที่เหลือ
- เล่นไฟล์หรือเปิดโฟลเดอร์ได้ทันที
- แยกเสียงจากวิดีโอที่บันทึกไว้
- เก็บประวัติการดาวน์โหลด

## วิธีติดตั้ง

1. กดปุ่มดาวน์โหลดด้านบน ไฟล์ติดตั้งจะถูกบันทึกทันที
2. เปิดไฟล์ที่ได้
3. เลือกภาษาและตำแหน่งติดตั้ง จากนั้นกด **ติดตั้ง**

การติดตั้งต้องใช้อินเทอร์เน็ต เพราะจะดาวน์โหลดเครื่องมือที่โปรแกรมใช้
(yt-dlp และ FFmpeg) แล้ว **เก็บสำเนาของตัวเองไว้ในโฟลเดอร์โปรแกรม**
โดยทั่วไปใช้เวลาราว 10 ถึง 30 วินาที

> **หากขึ้นข้อความ "Windows protected your PC"**
> ให้กด **More info → Run anyway**
> ข้อความนี้ขึ้นเพราะโปรแกรมทำโดยคนคนเดียวและไม่มีใบรับรองการเซ็นโค้ดแบบเสียเงิน
> ไม่ใช่ไวรัสแต่อย่างใด

หากต้องการถอนการติดตั้ง ใช้ **การตั้งค่า → แอป** หรือเปิด `Uninstall.exe`
ในโฟลเดอร์ติดตั้ง วิดีโอและเพลงที่ดาวน์โหลดไว้จะไม่ถูกลบ

## วิธีใช้งาน

1. คัดลอกที่อยู่วิดีโอจาก YouTube
2. กดปุ่ม **วางลิงก์** ในโปรแกรม
3. เสร็จแล้ว รายการจะปรากฏในลิสต์และเริ่มดาวน์โหลดทันที

หากต้องการเลือกคุณภาพหรือคำบรรยายเป็นรายวิดีโอ ให้ปิด **ดาวน์โหลดทันที**
จากนั้นทุกครั้งที่เพิ่มลิงก์ หน้าต่างตัวเลือกจะเปิดขึ้นมา

ถ้าวางที่อยู่เพลย์ลิสต์หรือช่อง จะเห็นรายการวิดีโอทั้งหมดพร้อมช่องติ๊ก
เพื่อเลือกเฉพาะที่ต้องการ

## คำถามที่พบบ่อย

**จู่ ๆ ก็ดาวน์โหลดไม่ได้**
เมื่อ YouTube เปลี่ยน เครื่องมือดาวน์โหลดก็ต้องเปลี่ยนตาม
โปรแกรมจะตรวจสอบให้วันละครั้ง แต่ถ้ารีบก็สั่งเองได้ที่
**เครื่องมือ → อัปเดต yt-dlp**

**ใช้ในเครือข่ายบริษัทไม่ได้**
ลองใส่ที่อยู่พร็อกซีใน **การตั้งค่า → การเชื่อมต่อ**

**วิดีโอที่จำกัดอายุดาวน์โหลดไม่สำเร็จ**
ที่ **การตั้งค่า → การลงชื่อเข้าใช้** ให้เลือกเบราว์เซอร์ที่คุณลงชื่อเข้า YouTube ไว้
