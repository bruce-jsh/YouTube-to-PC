# เมื่อ Windows ไม่ยอมให้ดาวน์โหลดหรือติดตั้ง

</div>

---

**คำเตือนทั้งหมดในหน้านี้ไม่ได้แปลว่าโปรแกรมอันตราย**

Windows เชื่อถือโปรแกรมจากชื่อเสียง และชื่อเสียงนั้นซื้อได้ด้วยใบรับรองการเซ็น
โปรแกรมนี้เขียนโดยคนคนเดียวและยังไม่มีใบรับรอง Windows จึงมองว่าเป็นคนแปลกหน้า
และเตือนเสียงดัง

หาหน้าจอที่คุณเจอจากด้านล่าง ส่วนใหญ่กดสามครั้งก็จบ

---

## วิธีที่เร็วที่สุด: เปลี่ยนเบราว์เซอร์

ตัวที่เข้มงวดคือ Microsoft Edge **Chrome และ Firefox ดาวน์โหลดไฟล์นี้โดยไม่ทักอะไรเลย**

ถ้า Edge ขวางอยู่ ให้เปิด
[หน้าดาวน์โหลด](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
ด้วย Chrome หรือ Firefox แล้วกดปุ่มที่นั่น เท่านี้ก็จบ

ถ้าอยากใช้ Edge ต่อ อ่านด้านล่าง

---

## 1. Edge บล็อกการดาวน์โหลด

จะมีข้อความว่าไฟล์นี้ **ไม่ค่อยมีคนดาวน์โหลด**

<img src="images/block-1-notice.png" width="380" alt="Edge แจ้งว่าไฟล์นี้ไม่ค่อยมีคนดาวน์โหลด">

**ขั้นที่ 1** กด `Ctrl` + `J` เพื่อเปิด **ดาวน์โหลด** แล้วกดปุ่ม **…** ที่แถวนั้น

<img src="images/block-2-menu.png" width="520" alt="เมนูสามจุดที่มีเก็บไว้และรายงานว่าไฟล์นี้ปลอดภัย">

**ขั้นที่ 2** เลือก **เก็บไว้** (Keep)

**ขั้นที่ 3** จะมีหน้าต่างที่สองขึ้นมา ตรงนี้คือจุดที่คนติดกันมากที่สุด เพราะปุ่มที่เห็น
มีแต่ **ลบ** (Delete) ให้กด **ลูกศรเล็ก ๆ ข้างปุ่มลบ** แล้วเลือก **เก็บไว้อยู่ดี**
(Keep anyway)

<img src="images/block-3-keep.png" width="370" alt="กดลูกศรข้างปุ่มลบเพื่อให้เก็บไว้อยู่ดีปรากฏขึ้น">

จากนั้นการดาวน์โหลดจะเสร็จตามปกติ

> ตอนที่อยู่ในเมนูนั้น กด **รายงานว่าไฟล์นี้ปลอดภัย** (Report this file as safe)
> ด้วยก็ดี ยิ่งมีคนรายงานมาก คำเตือนนี้ก็ยิ่งหายเร็วขึ้นสำหรับทุกคน

---

## 2. ขึ้น "Windows protected your PC" ตอนเปิด

อาจมีหน้าต่างสีน้ำเงินขึ้นมา โดยมีแค่ปุ่ม **Don't run**

1. กดลิงก์เล็ก ๆ **More info** ที่อยู่ใต้ข้อความ มันเป็นตัวอักษรธรรมดาไม่ใช่ปุ่ม
   จึงมองข้ามได้ง่าย
2. จะมีปุ่มใหม่โผล่ด้านล่างว่า **Run anyway**
3. กดปุ่มนั้น

หน้าต่างนี้มักขึ้นในครั้งแรกที่เปิดไฟล์บนเครื่องนั้น เมื่ออนุญาตไปแล้วครั้งหนึ่ง Windows จะไม่ถามอีกบนเครื่องเดิม

---

## 3. โปรแกรมป้องกันไวรัสลบไฟล์ทิ้ง

ดาวน์โหลดเสร็จแล้วแต่ไฟล์หายไป

1. เปิด **Windows Security** จากเมนู Start
2. ไปที่ **Virus & threat protection**
3. ใน **Protection history** หารายการ `YouTubeToPC-Setup`
4. เปิดรายการนั้น กด **Actions** แล้วเลือก **Allow on device**
5. ดาวน์โหลดไฟล์ใหม่อีกครั้ง

ถ้าใช้โปรแกรมอื่น (Avast, AVG, Norton) ให้เพิ่มข้อยกเว้นให้ไฟล์ติดตั้ง หรือให้โฟลเดอร์
ที่ติดตั้ง

```
C:\Program Files\YouTube to PC
```

หรือหยุดการป้องกันแบบเรียลไทม์สักครู่ ติดตั้งให้เสร็จ แล้วเปิดกลับ

---

## 4. ติดตั้งไปได้ครึ่งทางแล้วหยุด

ข้อความเกี่ยวกับ yt-dlp หรือให้ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต แปลว่าตัวติดตั้ง
ดาวน์โหลดเครื่องมือที่ต้องใช้ไม่ได้

ตัวติดตั้งมีขนาดราว 1 MB เท่านั้น ระหว่างติดตั้งมันจะดาวน์โหลด yt-dlp, FFmpeg และ
QuickJS จากหน้าทางการของแต่ละโครงการ รวมประมาณ 110 MB แล้วเก็บสำเนาของตัวเองไว้ใน
โฟลเดอร์โปรแกรม

ลองตามลำดับนี้

**ก. ปิด VPN แล้วติดตั้งใหม่** เป็นสาเหตุที่พบบ่อยที่สุด

**ข. อนุญาตผ่านไฟร์วอลล์** **Windows Security** → **Firewall & network protection**
→ **Allow an app through firewall** → **Change settings** → **Allow another app** →
**Browse** เลือกไฟล์ติดตั้ง → **Add** แล้วติ๊กทั้ง **Private** และ **Public**

**ค. ลองเครือข่ายอื่น** เครือข่ายของบริษัท โรงเรียน และบางที่สาธารณะ บล็อก GitHub
ซึ่งเป็นที่มาของเครื่องมือ ใช้เน็ตที่บ้านหรือแชร์เน็ตจากมือถือมักจะผ่าน

---

## 5. ไม่มีอะไรเกิดขึ้นเลย

- **ดับเบิลคลิกแล้วเงียบ** คลิกขวาที่ไฟล์แล้วเลือก **Run as administrator**
- **"This app can't run on your PC"** ต้องใช้ Windows 10 หรือ 11 แบบ 64 บิต
  ตรวจได้ที่ **Settings** → **System** → **About**
- **ไฟล์มีขนาด 0 ไบต์หรือเปิดไม่ได้** ดาวน์โหลดขาดกลางคัน ให้ลบแล้วโหลดใหม่

---

## ตรวจว่าไฟล์เป็นของแท้

ทุกหน้าเผยแพร่จะระบุค่า SHA-256 ของตัวติดตั้งไว้ เปิด PowerShell ในโฟลเดอร์ที่มีไฟล์
แล้วรัน

```powershell
Get-FileHash .\YouTubeToPC-Setup-1.3.3.exe -Algorithm SHA256
```

ถ้าตรงกับค่าใน
[หน้าเผยแพร่](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
แปลว่าคุณได้ไฟล์ที่เผยแพร่ไว้จริง ๆ และไม่มีใครแก้ไขมัน

## ทำไมถึงเป็นแบบนี้

ใบรับรองการเซ็นมีค่าใช้จ่ายทุกปี และถ้าไม่มี Windows ก็ไม่มีทางรู้ว่าใครเขียนโปรแกรมนี้

สิ่งที่มีแทนคือ ซอร์สโค้ดเปิดเผย ทุกรุ่นถูกสร้างอย่างเปิดเผยด้วย
[GitHub Actions](https://github.com/bruce-jsh/YouTube-to-PC/actions) และค่าแฮช
ด้านบนให้คุณยืนยันเองได้ว่าได้ไฟล์จากการสร้างครั้งนั้นจริง

การขอใบรับรองกำลังดำเนินอยู่ เมื่อเสร็จแล้วคำเตือนเหล่านี้จะหายไป
