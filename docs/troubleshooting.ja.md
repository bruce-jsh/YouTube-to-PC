# ダウンロードやインストールがブロックされるとき

</div>

---

**ここに出てくる警告は、どれも危険という意味ではありません。**

Windows はソフトを評判で信頼します。その評判は署名証明書を買って得るものです。
このプログラムは個人が作っていて証明書がまだないため、Windows は見知らぬソフトとして
扱い、強い言葉で警告します。

お使いの画面を下から探してください。たいてい 3 回押せば終わります。

---

## いちばん早い方法: 別のブラウザーで取得する

厳しいのは Microsoft Edge です。**Chrome と Firefox は何も言わずに取得できます。**

Edge で止まる場合は
[ダウンロードページ](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
を Chrome か Firefox で開いてボタンを押してください。それだけで解決します。

Edge のまま進めたい場合は以下をご覧ください。

---

## 1. Edge がダウンロードをブロックする

**一般的にダウンロードされていないファイル**という案内が表示されます。

<img src="images/block-1-notice.png" width="380" alt="よく取得されるファイルではないという Edge の案内">

**手順 1.** `Ctrl` + `J` で **ダウンロード** を開き、その行の **…** を押します。

<img src="images/block-2-menu.png" width="520" alt="保持と安全なファイルとして報告がある三点メニュー">

**手順 2.** **保持**(Keep) を選びます。

**手順 3.** 二つめの窓が出ます。ここで多くの人がつまずきます。見えているボタンは
**削除**(Delete) だけです。**削除の横にある小さな矢印**を押すと
**保持する**(Keep anyway) が現れます。

<img src="images/block-3-keep.png" width="370" alt="削除の横の矢印を押すと保持するが現れる">

これでダウンロードが最後まで進みます。

> そのメニューにある **安全なファイルとして報告**(Report this file as safe) も
> 押していただけると助かります。報告が集まるほど、次の人はこの警告を見なくなります。

---

## 2. 実行時に「Windows によって PC が保護されました」と出る

青い窓が現れ、**実行しない** ボタンだけが見えることがあります。

1. 文章の下にある小さな **詳細情報** リンクを押します。ボタンではなくただの文字で、
   見落としやすい場所です
2. 下に **実行** ボタンが新しく現れます
3. それを押します

この窓はそのパソコンで初めて実行するときに出ます。一度許可すれば、同じパソコンでは
二度と尋ねられません。

---

## 3. ウイルス対策ソフトがファイルを消した

ダウンロードが終わったのにファイルが消えています。

1. スタートメニューから **Windows セキュリティ** を開きます
2. **ウイルスと脅威の防止** に進みます
3. **保護の履歴** で `YouTubeToPC-Setup` の項目を探します
4. 開いて **操作** を押し、**デバイスで許可** を選びます
5. もう一度ダウンロードします

他のウイルス対策ソフト (Avast、AVG、Norton など) をお使いなら、インストーラーか
インストール先フォルダーを除外に追加してください。

```
C:\Program Files\YouTube to PC
```

またはリアルタイム保護を少しの間だけ止め、インストール後に戻してください。

---

## 4. インストールが途中で止まる

yt-dlp を取得できない、インターネット接続を確認してほしい、といった表示が出る場合、
インストーラーが必要な道具を取得できていません。

インストーラーは 1 MB ほどです。インストール中に yt-dlp、FFmpeg、QuickJS を各公式
ページから合計 110 MB ほど取得し、プログラムのフォルダー内に自分用の控えとして
保管します。

順番に試してください。

**a. VPN を切ってやり直す。** いちばん多い原因です。

**b. ファイアウォールで許可する。** **Windows セキュリティ** →
**ファイアウォールとネットワーク保護** → **ファイアウォールによるアプリケーションの許可**
→ **設定の変更** → **別のアプリの許可** → **参照** でインストーラーを選び **追加**、
**プライベート** と **パブリック** の両方にチェック。

**c. 別のネットワークで試す。** 会社や学校、一部の公共ネットワークは道具の取得元で
ある GitHub を遮断します。自宅の回線やスマートフォンのテザリングならたいてい通ります。

---

## 5. まったく反応がない

- **ダブルクリックしても何も起きない。** 右クリックして
  **管理者として実行** を選んでください。
- **「この PC では実行できません」。** 64 ビットの Windows 10 または 11 が必要です。
  **設定 → システム → バージョン情報** で確認できます。
- **ファイルが 0 バイト、または開けない。** 途中で切れています。削除してもう一度
  取得してください。

---

## 受け取ったファイルが本物か確かめる

リリースページにはインストーラーの SHA-256 が載っています。ファイルのあるフォルダーで
PowerShell を開き、次を実行してください。

```powershell
Get-FileHash .\YouTubeToPC-Setup-1.3.1.exe -Algorithm SHA256
```

[リリースページ](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
の値と一致すれば、公開されたものそのままで、誰も手を加えていないという意味です。

---

## なぜこうなるのか

署名証明書には毎年の費用がかかります。証明書がなければ、Windows はこのプログラムを
誰が書いたのか知る手立てがありません。

その代わりソースコードは公開されていて、配布物はすべて
[GitHub Actions](https://github.com/bruce-jsh/YouTube-to-PC/actions) が公開の場で
ビルドしており、上のハッシュでそのビルドかどうかをご自分で確認できます。

署名を得るための作業を進めています。終われば、これらの警告はなくなります。
