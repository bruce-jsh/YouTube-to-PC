# Windows татах буюу суулгахыг зөвшөөрөхгүй байвал

</div>

---

**Энд гарч буй сэрэмжлүүлгүүдийн аль нь ч программ аюултай гэсэн утга агуулаагүй.**

Windows программд нэр хүндээр нь итгэдэг бөгөөд тэр нэр хүндийг гарын үсгийн
гэрчилгээ худалдаж авснаар олдог. Энэ программыг нэг хүн бичсэн бөгөөд гэрчилгээ
хараахан байхгүй тул Windows түүнийг танихгүй хүн мэт үзэж, чанга дуугаар
сэрэмжлүүлдэг.

Тохиолдсон цонхоо доороос олоорой. Ихэнх нь гурван товшилтоор шийдэгдэнэ.

---

## Хамгийн хурдан арга: өөр хөтөч ашиглах

Хатуу нь бол Microsoft Edge. **Chrome болон Firefox энэ файлыг юу ч хэлэлгүй
татдаг.**

Edge саад болж байвал
[татах хуудсыг](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
Chrome эсвэл Firefox дээр нээгээд тэндээс товчийг дарна уу. Үүгээр л болно.

Edge дээр үргэлжлүүлэхийг хүсвэл доошоо уншина уу.

---

## 1. Edge татахыг хориглож байна

Энэ файлыг **ховор татдаг** гэсэн мэдэгдэл гарч ирнэ.

<img src="images/block-1-notice.png" width="380" alt="Edge уг файлыг ховор татдаг гэж мэдэгдэж байна">

**Алхам 1.** `Ctrl` + `J` дарж **Татсан зүйлс** жагсаалтыг нээгээд тухайн мөрний
**…** товчийг дарна.

<img src="images/block-2-menu.png" width="520" alt="Хадгалах болон файлыг аюулгүй гэж мэдэгдэх сонголттой гурван цэгийн цэс">

**Алхам 2.** **Хадгалах** (Keep) гэснийг сонгоно.

**Алхам 3.** Хоёр дахь цонх гарч ирнэ. Ихэнх хүн яг энд гацдаг: харагдаж буй цорын
ганц товч дээр **Устгах** (Delete) гэж бичсэн байдаг. **Устгахын хажууд байгаа
жижиг сумыг** дарвал **Ямар ч байсан хадгалах** (Keep anyway) гарч ирнэ.

<img src="images/block-3-keep.png" width="370" alt="Устгахын хажуугийн сумыг дарвал Ямар ч байсан хадгалах гарч ирнэ">

Үүний дараа татаж авалт хэвийн дуусна.

> Тэр цэсэнд байхдаа **Энэ файлыг аюулгүй гэж мэдэгдэх** (Report this file as safe)
> гэснийг дарвал сайн. Хэдий олон хүн мэдэгдэнэ, энэ сэрэмжлүүлэг бүгдэд төдий
> хурдан алга болно.

---

## 2. Ажиллуулахад "Windows protected your PC" гарч ирэх

Цэнхэр цонх гарч ирэн, зөвхөн **Don't run** товч харагдаж болно.

1. Бичгийн доор байгаа жижиг **More info** холбоосыг дарна. Энэ нь товч биш, зүгээр
   нэг бичиг тул амархан анзаарагддаггүй
2. Доод талд **Run anyway** гэсэн шинэ товч гарч ирнэ
3. Түүнийг дарна

Энэ цонх ихэвчлэн тухайн компьютер дээр анх удаа ажиллуулахад гарч ирдэг. Нэг удаа
зөвшөөрсний дараа Windows тэр компьютер дээр дахин асуухгүй.

---

## 3. Вирусны эсрэг программ файлыг устгасан

Татаж дуусаад файл алга болсон байна.

1. Эхлэх цэснээс **Windows Security** нээнэ
2. **Virus & threat protection** руу орно
3. **Protection history** хэсгээс `YouTubeToPC-Setup` бичлэгийг олно
4. Нээгээд **Actions** дарж **Allow on device** сонгоно
5. Файлыг дахин татна

Өөр программ (Avast, AVG, Norton) ашиглаж байвал суулгагч файл эсвэл суулгах
хавтсанд үл хамаарах дүрэм нэмнэ үү.

```
C:\Program Files\YouTube to PC
```

Эсвэл бодит цагийн хамгаалалтыг хэсэг зуур зогсоож, суулгаад дахин асаана.

---

## 4. Суулгалт эхлээд дундаа зогсох

yt-dlp-тэй холбоотой эсвэл интернэт холболтоо шалгахыг хүссэн мэдэгдэл гарвал,
суулгагч хэрэгтэй программуудаа татаж чадаагүй гэсэн үг.

Суулгагч ердөө 1 МБ орчим. Суулгах явцдаа yt-dlp, FFmpeg, QuickJS-ийг тус тусын
албан ёсны хуудаснаас нийт 110 МБ орчим татаж, өөрийн хуулбарыг программын хавтас
дотор хадгалдаг.

Дарааллаар нь туршина уу.

**а. VPN-ээ унтраагаад дахин суулгана уу.** Хамгийн түгээмэл шалтгаан нь энэ.

**б. Галт ханаар зөвшөөрнө.** **Windows Security** →
**Firewall & network protection** → **Allow an app through firewall** →
**Change settings** → **Allow another app** → **Browse** дээрээс суулгагчийг сонгож
**Add**, дараа нь **Private**, **Public** хоёуланг нь тэмдэглэнэ.

**в. Өөр сүлжээ туршина уу.** Байгууллага, сургууль болон зарим нийтийн сүлжээ
программуудыг татдаг газар болох GitHub-ийг хаадаг. Гэрийн холболт эсвэл утасны
сүлжээ ихэвчлэн ажилладаг.

---

## 5. Огт хариу үйлдэл алга

- **Хоёр товшиход юу ч болохгүй.** Файл дээр баруун товшиж
  **Run as administrator** сонгоно уу.
- **"This app can't run on your PC".** 64 битийн Windows 10 эсвэл 11 хэрэгтэй.
  **Settings**, **System**, **About** хэсгээс шалгана уу.
- **Файл 0 байт эсвэл нээгдэхгүй байна.** Татаж авалт тасарсан байна. Устгаад дахин
  татна уу.

## Файл жинхэнэ эсэхийг шалгах

Хувилбар бүрийн хуудсанд суулгагчийн SHA-256 утга бичигдсэн байдаг. Файл байгаа
хавтсанд PowerShell нээгээд дараахыг ажиллуулна уу.

```powershell
Get-FileHash .\YouTubeToPC-Setup-1.3.2.exe -Algorithm SHA256
```

Хэрэв
[хувилбарын хуудсан](https://github.com/bruce-jsh/YouTube-to-PC/releases/latest)
дээрх утгатай таарч байвал, нийтлэгдсэн яг тэр файл бөгөөд хэн ч өөрчлөөгүй гэсэн
үг.

## Яагаад ийм болдог вэ

Гарын үсгийн гэрчилгээ жил бүр мөнгө шаарддаг бөгөөд үүнгүйгээр Windows энэ
программыг хэн бичсэнийг мэдэх ямар ч арга байхгүй.

[GitHub Actions](https://github.com/bruce-jsh/YouTube-to-PC/actions) олны өмнө
угсардаг бөгөөд дээрх хэш нь яг тэр угсралтыг авсан эсэхээ өөрөө шалгах
боломжийг олгоно.

Гарын үсэг авах ажил үргэлжилж байна. Дуусмагц эдгээр сэрэмжлүүлэг алга болно.
